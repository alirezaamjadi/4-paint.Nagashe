# 🎨 4 Naghashti Emtiazi (4 Score Drawing)

A simple and interactive team-based drawing and scoring game developed in **Python** using the **Pygame** library.

---

## 🚀 Overview

This game allows two teams, each with two players, to compete by drawing and scoring points. Features include:

* 📝 Customizable team and player names
* 🎨 Drawing canvas with colors & eraser
* ➕➖ Score adjustment buttons
* 📓 Built-in notebook to take notes
* 🖥️ Fullscreen & windowed modes
* 🏆 Final champion announcement screen

---

## 💻 How to Run

1. Install Python 3.8+
2. Install Pygame:

   ```bash
   pip install pygame
   ```
3. Clone this repo and run:

   ```bash
   python game.py
   ```

---

## 📁 Code Structure

* **game.py**: Main game file
* Classes: `SetupScreen`, `GameScreen`, `Button`
* Modular, readable, and commented code
