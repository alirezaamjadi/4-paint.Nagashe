## 🇺🇸 English

### 🎮 About the Game

**4 Nagashe Emtiaze (4 Score Painting)** is an exciting team-based game developed by **Alireza Amjadi** in **2025** using **Python** programming language and the powerful **Pygame** library. In this game, two teams with customizable names and players compete by drawing and scoring points to reach the final target and become the champion.

### ⚙️ Features

* 👥 Customizable team names and players
* 🔢 Manual increase and decrease of each team’s score
* 🎨 Drawing tools with multiple color options
* 🧽 Eraser tool to fix drawings
* 📝 Built-in notebook for taking notes and comments
* 🏆 Winner screen showing detailed champion info: team name, players, and final score
* 🔄 Toggle between fullscreen and windowed mode
* 💾 Save and load notes from a separate file

### 🚀 How to Run

1. Download the game installation file from the **Game File** section (RAR archive).
2. Password for the compressed file: `amjadi4paint`
3. Extract the files.
4. Make sure **Python** and **Pygame** are installed on your system.
5. Run the `game4paint` file to start the game.
